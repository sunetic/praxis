# MySQL DBA Cases

内置 MySQL DBA suite（`2.1.0`）在隔离的 MySQL 8.4 fixture 上评估十个长任务。`praxis` profile 使用真实后端与 Chat 链路；`model` profile 使用固定模型对比 harness。

## Case 目录

| ID | 场景 | 关键检查 |
| --- | --- | --- |
| M01 | 数据库整体健康基线 | 对象/容量、连接/事务、InnoDB buffer pool、索引/负载与不确定性 |
| M02 | 慢订单看板 | 安全执行计划、真实过滤条件、复合索引取舍与上线验证 |
| M03 | InnoDB 阻塞链 | 识别根阻塞者和等待者，报告观察到的持续时间，并按风险说明安全处置顺序 |
| M04 | 连接与事务压力 | 连接上限、两个空闲事务、报表连接池归因与风险分离 |
| M05 | InnoDB purge 与碎片排查 | 删除 churn、空间/purge 证据、目标表与谨慎维护建议 |
| M06 | 索引组合审计 | 重复定义、不可见索引、工作负载证据与保留/删除/新增候选 |
| M07 | 优化器估算与 histogram | 估算/实际行数、相关列、histogram 边界与验证方案 |
| M08 | 支付数据对账 | 六类合成异常的精确计数、样本和规则假设 |
| M09 | 最小权限 | 通配 host、全局/schema 权限，以及不暴露哈希的可回退整改草案 |
| M10 | 政策支撑的事件判断 | 用命名来源支撑政策特有结论、结合实时证据并遵守审批边界 |

## Case 边界

每个 case 都定义任务、fixture 状态、参考答案检查、可选权威来源要求和禁止结果，不规定工具选择或最少调用次数。Runner 会保留原始证据，并在每次 attempt 后验证数据、安全账号、feature flag、索引定义和维护历史没有发生禁止变更。

题库只覆盖常见生产 DBA 工作：健康基线、慢 SQL、阻塞、连接与事务压力、维护、索引、优化器统计、数据一致性、最小权限和事件决策。Case 不得针对 Praxis 的特定 Skill、Prompt、verifier、重试机制或工具调用路径；这些组件的确定性行为由 tests 验证，它们对通用数据库任务的影响只能通过 Eval 结果体现。

Case 定义版本化保存在公开 Eval corpus 中，只使用合成数据与账号。它们是可复现的质量基准，不是生产环境诊断手册。

前置条件、命令、参数、结果分类和报告产物见 [Eval 概览](evaluation.md)。
