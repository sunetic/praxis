# Agent

Agent 是一套可复用的任务配置：它定义角色、工作目标、可用工具和 Skill。它适合保存那些仍需要模型根据现场证据做判断、但不值得每次从头解释的方法。

## 创建方式

- 在 Agent 页面通过引导创建；
- 手动填写名称、说明、提示词，并选择工具与 Skill；
- 在一段效果稳定的 Chat 中保存为 Agent，再到 Agent 页面校正配置。

从对话保存并不是逐字复制聊天记录。保存结果应提炼任务目标、方法、工具和专业知识，让新的会话可以在不同时间或数据源上重新执行。

## 运行方式

在 Agent 列表中选择运行，必要时先指定数据源。新会话使用该 Agent 的配置，但会读取当时的真实数据库状态，不是重放旧答案。

Agent 也可以作为 Scheduler 的目标。定时运行时没有人在旁边补充上下文，因此调度中的输入指令应明确范围、期望输出和失败边界。

## Agent 与 Function 的选择

- 需要现场推理、动态选择工具：使用 Agent。
- 输入输出已经固定，追求更强重复性：使用 Function。
- 仍在探索的方法先做 Agent，稳定后再考虑 Function。

内置 Agent 可能只读；自定义 Agent 可以编辑和删除。删除前应确认没有 Scheduler 依赖它。
