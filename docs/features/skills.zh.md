# Skills

Skill 是给 Agent 使用的领域方法和规则。它以易审阅的文本描述“遇到某类问题时应该检查什么、如何判断、有哪些限制”，不负责保存数据库凭据，也不直接代表一次运行。

## 适合沉淀什么

- 慢 SQL、锁等待、复制或 Vacuum 等诊断步骤；
- 团队约定的证据清单和输出格式；
- 某数据库类型特有的注意事项；
- 必须始终遵守的安全或合规规则。

Skill 可以标记适用范围：通用、MySQL、PostgreSQL 或 OceanBase。启用 `always apply` 后，它会默认加入相关会话；普通 Skill 则可由 Agent 配置或按任务需要加载。

## 编写建议

一份实用 Skill 应包含适用条件、调查顺序、关键证据、禁止动作、判断阈值和结束标准。避免把某次事故的具体主机、账号或密钥写进去，也不要把 Skill 写成没有验证步骤的长篇背景材料。

内置 Skill 用于提供开箱即用的方法，内容在界面中受到保护；自定义 Skill 可在列表或引导式构建页中创建和维护。
