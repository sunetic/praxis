# 服务

服务用于登记数据库之外的外部控制面，并把它与某个集群或数据源关联。它和数据源不同：数据源直接访问数据库；服务连接的是管理 API。

当前界面提供 OCP API 服务配置，可填写地址、端口和认证信息，并在保存前或列表中测试连接。关联资源可以是一个集群标识，也可以是已有数据源。

## 使用建议

- 先确认 Praxis 主机能够访问目标管理 API；
- 使用专用、最小权限的服务账号；
- 通过“测试连接”验证认证和地址，不要只依据配置是否保存成功；
- 一个服务只关联清晰的资源范围，避免同一凭据承担无关集群；
- 删除前确认没有 Agent 或自动化流程依赖它。

服务的能力取决于具体服务类型和账号权限。配置成功只代表接口可达，不代表任意管理操作都被允许。
