# 知识库

知识库让 Agent 在数据库实时证据之外，引用团队文档、操作手册、事件分级规则等本地资料。它适合回答“我们的规范怎么说”，但不能替代对当前数据库状态的查询。

## 基本流程

1. 创建知识库，填写名称、说明和标签。
2. 上传 Markdown（`.md`）文档。
3. 等待文档处理完成，并在详情页检查内容。
4. 在任务中要求 Agent 同时引用知识库规则和数据库现场证据。

部分安装包可以一次安装一组内置知识内容，并在知识库列表中管理安装状态。

## 可靠使用

- 文档要标明适用系统、版本和更新时间；
- 政策阈值与现场指标应分别引用，避免把旧文档当实时事实；
- 对关键结论要求说明依据来自哪类材料；
- 更新规则后重新运行相关 Eval case，确认检索和决策仍符合预期。

知识库内容会成为模型上下文的一部分。不要上传本不应交给所配置模型服务处理的敏感信息。
