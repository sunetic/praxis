# 渠道

渠道把 Praxis 的消息发送到外部协作平台。当前可配置：

- 钉钉自定义机器人；
- Slack Incoming Webhook；
- Telegram Bot。

飞书和企业微信会显示为尚未开放，不应按已支持能力使用。

## 配置方式

每种渠道都有引导步骤和测试消息。钉钉可配置签名、关键词或 IP 白名单等安全模式，以及 Markdown 消息模板和 @ 提醒；Slack 使用 Incoming Webhook，可设置用户名、图标和频道；Telegram 使用 Bot Token 与 Chat ID，并可选择解析模式和静默通知。

## 安全建议

- Webhook、签名 Secret 和 Bot Token 都视为凭据；
- 使用平台侧的最小发送权限，并限制目标群或频道；
- 保存后发送测试消息，确认格式、接收对象和限流行为；
- 不要在消息模板中默认包含数据库密码、完整 SQL 参数或敏感结果集。

渠道供应商可能限流或拒绝消息。自动化任务应把“任务执行成功”和“通知发送成功”作为两个结果检查。
