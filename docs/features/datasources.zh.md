# 数据源

数据源定义 Praxis 可以连接的数据库范围，是 Chat、Function、Scheduler 和分析工作区访问真实数据的基础。

## 当前支持

- MySQL；
- PostgreSQL。

连接表单会根据数据库类型使用常见默认端口，也允许填写自定义主机、端口、用户名和默认数据库。

## 推荐接入流程

1. 在数据库侧创建专用的最小权限账户。
2. 新增数据源并填写连接信息。
3. 在保存前测试连接。
4. 用一个只读 Chat 任务验证能够读取预期 schema，且不能访问超出范围的数据。
5. 再把数据源交给 Agent、Function 或 Scheduler 使用。

## 安全与运维

- 生产诊断首选只读账户，不要复用管理员账号。
- 网络连通性由 Praxis 所在主机决定；浏览器能访问数据库地址并不代表容器能访问。
- 修改加密密钥会导致已保存密码不可解密。
- 删除数据源前，先检查依赖它的 Scheduler、Function 和分析任务。

如果同一集群有不同租户或权限边界，建议建立独立数据源，使作用域在运行记录中保持清晰。
