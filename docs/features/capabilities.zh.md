# 能力与安全

**能力** 页面展示模型和平台当前可使用的结构化动作。它帮助用户回答两个问题：Agent 能做什么，以及某个动作有什么参数和风险边界。

## 两类能力

- **LLM Tools**：读取 schema、执行查询、获取执行计划、搜索知识等数据面能力；
- **平台能力**：创建、修改、发布或运行 Praxis 对象等治理能力。

把两者区分开很重要。数据库查询需要数据库权限与 SQL 安全策略；平台对象变更需要对象级约束、确认和审计。模型只负责选择和填写动作，服务端仍会校验参数与权限。

## 查看详情

能力详情会显示描述和参数结构。使用前重点检查：

- 必填参数和目标对象；
- 是否可能改变数据库或平台状态；
- 是否要求人工确认；
- 重复执行是否安全；
- 失败后能否通过运行记录或追踪定位。

能力列表是当前运行实例的事实来源。文档只解释产品语义，不承诺每个部署、版本或账号都拥有相同能力。
