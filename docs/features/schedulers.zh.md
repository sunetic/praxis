# Scheduler

Scheduler 按 cron 或固定间隔运行已配置的 Function 或 Agent，用于巡检、采集、周期分析和通知。

## 两种目标

| 目标 | 适合的任务 | 特点 |
| --- | --- | --- |
| Function | 输入输出固定、需要更强重复性 | 运行已发布版本，可传 JSON 参数 |
| Agent | 需要模型读取现场并动态判断 | 使用固定开场指令，结果会受模型和现场状态影响 |

## 创建与运行

创建时选择目标，填写任务名称、时间规则和输入。界面可以根据自然语言意图协助生成时间配置和参数。保存后可立即运行、暂停、重新启用或编辑，并在运行记录中查看状态与结果。

失败重试由最大重试次数和退避时间控制。重试适合短暂网络故障或供应商限流，不应掩盖持续的权限、SQL 或任务设计错误。

## 定时 Agent 的注意事项

定时 Agent 没有交互式追问机会，因此输入应包含数据源范围、时间窗口、证据要求、输出格式和禁止动作。对关键任务至少手动运行一次，并确认它在缺少数据、模型限流和工具失败时会给出可理解的结果。

内置 Scheduler 的可编辑范围可能受限，自定义 Scheduler 才能完整管理生命周期。
