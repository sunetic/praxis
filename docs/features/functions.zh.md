# Function

Function 把已经比较清晰的数据库任务封装为可复用执行单元。与 Agent 相比，它更强调明确输入、可测试输出和发布版本，适合确定性更强的查询、计算与受控操作。

## 构建流程

1. 新建 Function，描述目标和输入输出。
2. 在 Build Chat 中让构建 Agent生成或调整草稿。
3. 选择代表性数据源和参数，在测试面板检查实际业务结果。
4. 修正问题，直到验证结果满足预期。
5. 发布一个可运行版本。

草稿和已发布版本是两个不同状态。构建期测试使用受限路径；生产调用和 Scheduler 使用已发布版本。修改草稿不会自动改变正在使用的发布版本。

## 使用方式

- 在 Function 列表中填写参数并直接调用；
- 查看运行历史、状态、耗时和输出；
- 被 Scheduler 周期触发；

## 验收重点

不要只检查“运行成功”。还应检查输入边界、返回字段、空数据、错误路径、查询范围、执行时间，以及写操作是否符合预期。涉及真实变更时，应先用非生产数据验证，并保留清晰的人工确认与回退方案。
