# 设置

设置页集中管理模型、构建引擎和安全开关。

## LLM

填写 API Key、模型名和 OpenAI 兼容 Base URL，并配置上下文窗口和自动压缩阈值。模型名必须与服务端实际支持的名称一致。

更换模型后，先完成一次普通 Chat 和工具调用验证；如果用于长期或重要任务，再运行 [Eval](../reliability/evaluation.md) 比较可靠性、事实依据和供应商可用性。

## 构建引擎

Function 构建可使用内置引擎，或配置外部 CLI。外部 CLI 需要先通过连接测试，平台可能补充非交互运行所需参数。配置成功不代表生成结果已经通过业务验收。

## 安全

SQL 写操作默认关闭。只有明确需要、数据源账号已最小化并且流程包含确认与回退时才应开启。设置变更应与数据库侧权限配合；平台开关不能替代数据库自身的访问控制。

API Key 等敏感字段不应出现在截图、Issue、Eval 报告或提交记录中。
