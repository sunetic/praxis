# Skills

## Conventions

- Directory: `skills/<database>/`
- Format: `Markdown + YAML Front Matter`
- Scanning: recursively scan `skills/`, ignoring `README.md`
- Always-on: `always_apply: true`

Bundled diagnostic Skills are opt-in domain knowledge. The shared Agent
instructions govern conversation behavior; no global Skill requires fixed
diagnostic layers or a confirmation between already-authorized read operations.
